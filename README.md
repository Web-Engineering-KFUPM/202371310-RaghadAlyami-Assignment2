# Raghad Alyami — Personal Portfolio

## Project Description

A responsive personal portfolio created for SWE363 Assignment 1.
The website introduces me, presents two projects, and includes
a demonstration contact form.

## Features

- About Me section and personal tagline
- Wasm creative services app project
- FPGA pedestrian light project
- Responsive project layout using Flexbox
- Greeting based on the visitor's local time
- Contact form validation and feedback

## Technologies

- HTML
- CSS
- JavaScript

## How to Run Locally

1. Download this repository using Code > Download ZIP and extract it,or clone it using Git.
2. Open the project folder.
3. Open index.html in a modern web browser.

To edit the website, open the folder in VS Code.
Save your changes and refresh the browser to see the updates.

## How to Use

Use the navigation links to move between About Me, Projects,and Contact.

The greeting is selected when the page loads, using the visitor's
device time.

Fill in Name, Email, and Message, then select Check Message.
The form validates the entries and displays feedback.
It does not send or store messages.
