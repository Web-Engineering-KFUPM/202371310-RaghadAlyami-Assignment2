# AI Usage Report

## Tools Used and Use Cases

I used ChatGPT to help debug parts of the portfolio, explain unfamiliar concepts, suggest test cases, and draft documentation.

## Benefits and Challenges

ChatGPT helped identify JavaScript event-listener errors. But it kept suggesting unfamiliar and complex techniques and topics as fixes.

## Learning Outcomes

I reinforced my understanding of responsive layouts using Flexbox and time-based greetings using the Date object. I also learned how event listeners handle form interactions and how textContent updates webpage content.

## Responsible Use and Modifications

I personalized the portfolio with my introduction, project information, and photographs. I reviewed the implementation, corrected errors with assistance, and tested the website’s layout and functionality.
